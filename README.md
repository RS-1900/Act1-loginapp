# Actividad 1: LoginApp
Tarea 1 de Desarrollo de aplicaciones móviles: Interfaz de inicio y registro de sesión

La aplicación desarrollada en Android Studio muestra una interfaz para iniciar sesión y registrarse.
La pantalla de Registro cuenta con 3 campos para introducir texto: Nombre completo, Usuario, y Contraseña y un boton para registrarse, que te lleva a la pantalla de Inicio, asi como un texto en la parte inferior que permite iniciar sesión si ya tienes una cuenta.
La pantalla de Iniciar sesión cuenta con 2 campos para introducir texto: Usuario y Contraseña, un botón para Iniciar sesión y un texto en la parte inferior para poder registrarte.


Instrucciones básicas para ejecutar el proyecto: Clonar el repositorio desde Android Studio -> Git -> Clone -> Clone Repository, descargar un emulador de Android (Pixel 7a) compilarlo y ejecutarlo.
